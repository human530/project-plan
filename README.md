# RA Xray AI — 類風濕性關節炎手部 X 光之 AI 自動損傷評分

> TISF（臺灣國際科學展覽會）高中個人科展專題的**完整研究規劃**。
> 用遷移學習 CNN 從手部 X 光自動產生 Sharp–van der Heijde（SvH）損傷分數，並以 ICC / Bland–Altman 驗證與專家評分的一致性、用 Grad-CAM 驗證可解釋性。
> 目標送件：2027 年 10–11 月　|　規劃製表：2026 年 6 月

---

## 這份規劃怎麼產生的

本規劃以「**AI 團隊 + 平行子代理**」模式產生：由一位總指揮（協調者）同時派出 4 個專責 AI 子代理，各自深化並**優化、改善**原始計畫書的一個領域，再整合成頂層架構與團隊協作藍圖。詳見 `docs/01-AI團隊與代理協作架構.md`。

## 可運作的 MVP 程式骨架

`src/raxray/` 已實作第一層 MVP 並**端到端驗證通過**（合成資料、CPU）：前處理 →
病人層級切分（防外洩）→ 遷移學習 CORN 序數模型 → 訓練 → 評估（ICC/Bland–Altman/
QWK + bootstrap CI）→ Grad-CAM 量化。執行 `python scripts/smoke_test.py` 可重現
（合成資料上達 ICC 0.93、Pearson 0.97、QWK 0.95；Grad-CAM 關節區能量 0.23 > 隨機 0.14）。
示意圖見 `docs/assets/`。

> ⚠️ smoke test 使用**合成資料**僅驗證管線正確性，不具臨床意義；真實使用需 docs/02 的資料。

## 四項最關鍵的優化（相對原始計畫）

1. **資料**：解耦「資料申請」與「MVP 開跑」——先用可直接下載的後援資料起步，並設資料 Gate 決策點，避免主資料集（RA2 DREAM 受控存取）延遲拖垮全程。
2. **模型**：MVP 保底改用**序數分級（CORN）**而非硬學「直接回歸總分」（文獻顯示全分數範圍回歸一致性會大幅下降）；骨幹明確選小（EfficientNet-B0/ResNet-18）以防小樣本過擬合。
3. **評估**：一致性主指標從 Pearson 相關改為 **ICC(2,1) + Bland–Altman**，破除「相關高 ≠ 一致」的陷阱；所有指標強制報告 95% 信賴區間，測試集只用一次。
4. **管理**：16 個月拆成**每月里程碑表**（含 Definition of Done 與依賴），風險登記從 6 條擴為 10 條，並建立研究日誌制度（評審當天需攜帶）。

## 重要聲明

本專案為**科展研究與輔助評分用途，非醫療診斷**。全程僅使用去識別化、授權清楚的公開資料，遵守研究倫理並配合 TISF 抄襲比對系統。所有文件中引用的外部數字均標註來源，不確定處標註「需進一步確認」。臨床敘述需由懂醫學/放射的人最終把關。
