# project-plan — Claudian Vault 🪨🤖

這是一個 **Claudian** = [Obsidian](https://obsidian.md) 知識庫（vault）+ [Claude Code](https://claude.com/claude-code) 工作區的合體 repo。

- 在**本地**用 Obsidian 打開這個資料夾 → 它會被辨識成一個 vault，可以寫雙向連結、看關係圖、用範本。
- 用 **Claude Code** → 我可以幫你新增 / 整理 / 重構筆記，再 commit、push。
- 用 **git** → 你的筆記有完整版本控制，可以跨裝置同步。

## 📂 結構

| 資料夾 | 用途 |
|--------|------|
| `Notes/` | 一般筆記（預設新筆記會放這裡） |
| `Daily/` | 每日筆記（Daily Notes 核心外掛） |
| `Templates/` | 範本（每日筆記、會議、專案） |
| `Attachments/` | 圖片、附件 |
| `.obsidian/` | Obsidian vault 設定 |

## 🚀 開始使用

1. 到 [obsidian.md](https://obsidian.md) 下載並安裝 Obsidian（這一步要在你自己的電腦做，我在雲端容器裡無法代裝）。
2. 把這個 repo clone 到本地：`git clone <repo-url>`。
3. 打開 Obsidian → **Open folder as vault** → 選這個資料夾。
4. 從 [[Welcome]] 這篇開始讀。

詳細說明見 [[Claudian 使用說明]]。
