# project-plan

一個專案規劃用的 **Obsidian vault**，透過 git 在桌機與手機之間同步。

- 入口筆記：[`Home.md`](Home.md)
- 桌機端讓 Claude Code 直接讀寫 vault：[`docs/obsidian-mcp-setup.md`](docs/obsidian-mcp-setup.md)

## 結構

| 資料夾 | 用途 |
|--------|------|
| `Projects/` | 各專案筆記（含 `Overview` 索引） |
| `Daily/` | 每日筆記 |
| `Meetings/` | 會議記錄 |
| `Notes/` | 一般筆記 |
| `Templates/` | 筆記範本（專案／每日／會議） |
| `Resources/` | 資源與附件 |

## 手機使用

用 Obsidian Sync、iCloud，或 Working Copy（git）把此 repo 同步到手機，
在 Obsidian 中以「開啟資料夾作為 vault」開啟即可。
