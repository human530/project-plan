# 專案總覽與架構定義

## 2. 範圍定義（Scope）

科展最大的失敗模式是**範圍蔓延做不完**。本專案以「分層推進」鎖定範圍，每層都有可獨立交付的成果。

### 2.1 範圍內（In Scope）

- 以**單張手部 X 光**為輸入，輸出**量化的 RA 損傷分數**（骨侵蝕 + 關節間隙狹窄）。
- 以**遷移學習 CNN** 為核心方法。
- 與**專家 SvH 分數**做量化一致性比對。
- 以 **Grad-CAM** 做可解釋性驗證。
- 在**免費 Colab** 上可重現的輕量流程。

### 2.2 分層交付（決定「做到哪」）

| 層級 | 定位 | 做什麼 | 是否本屆必達 |
|------|------|--------|--------------|
| **第一層 MVP** | 必達保底 | 整張手部 X 光 → 直接預測總分／嚴重度分級 | ✅ 必達 |
| **第二層 進階** | 主力亮點 | 偵測關鍵關節（MCP/PIP）裁切 → 逐關節評分 → 加總 | 🎯 主力，盡力完成 |
| **第三層 未來展望** | 延伸方向 | 完整管線（分割 + 偵測 + 逐關節侵蝕/間隙 + Transformer） | 🔭 不在本屆強求 |

### 2.3 範圍外（Out of Scope，明確排除）

- ❌ **臨床診斷**：本作品為研究與輔助評分用途，非醫療診斷工具。
- ❌ 多病種分類（RA / PsA / OA / 痛風）、疾病惡化軌跡預測、治療反事實——列為未來展望。
- ❌ 完整研究級 Transformer 管線的完整復現。
- ❌ 需付費算力或私有臨床資料的方案。

## 3. 研究問題與假設

| 類型 | 內容 |
|------|------|
| **主要問題** | 深度學習模型能否從手部 X 光自動估計 SvH 損傷分數，並與專家評分達到高度一致？ |
| **研究假設** | 經遷移學習的 CNN 可使預測分數與專家分數呈顯著正相關、誤差可接受；加入關節定位可進一步提升準確度。 |
| **次要問題** | 模型主要依據哪些影像區域做判斷？（以 Grad-CAM 檢驗是否對應骨侵蝕與關節間隙等臨床特徵） |

## 4. 系統架構（End-to-End Pipeline）

```
            ┌─────────────────────────────────────────────────────────────┐
            │                     RA Xray AI 系統管線                        │
            └─────────────────────────────────────────────────────────────┘

  [手部 X 光輸入]
        │
        ▼
  ┌──────────────┐     尺寸標準化 / window-level / 對比增強(CLAHE) / 去識別化檢核
  │  前處理模組   │ ──► 資料增強(旋轉/翻轉/亮度) / 類別不平衡處理(加權·重採樣)
  └──────────────┘
        │
        ├──────────────── 第一層 MVP ────────────────┐
        ▼                                            │
  ┌──────────────┐   遷移學習 CNN(ResNet/EfficientNet  │
  │  整圖評分模型 │   /MobileNet) + 回歸/分級頭         │
  └──────────────┘                                    │
        │                                             │
        ├──────────────── 第二層 進階 ───────────────┤
        ▼                                             │
  ┌──────────────┐   物件偵測/關鍵點(框出 MCP/PIP)     │
  │  關節定位模組 │ ──► 逐關節裁切 ──► 逐關節評分 ──► 加總
  └──────────────┘                                    │
        │                                             ▼
        ▼                                    ┌──────────────────┐
  ┌──────────────┐                           │  與專家 SvH 分數  │
  │ 預測損傷分數  │ ─────────────────────────►│  一致性比對        │
  └──────────────┘                           │ (ICC/Bland-Altman │
        │                                     │  /相關/RMSE/MAE)  │
        ▼                                     └──────────────────┘
  ┌──────────────┐
  │  Grad-CAM    │  熱區是否落在侵蝕/間隙關節 → 量化重疊比例
  │ 可解釋性分析  │
  └──────────────┘
```

**設計原則**：每個模組都能獨立驗證與交付；MVP 路徑（前處理 → 整圖評分 → 比對 → Grad-CAM）即可構成一份完整科展作品，進階模組為加分。

## 6. 成功標準（保守、誠實）

科展重視**科學方法的嚴謹**而非「最高分」。負結果加上誠實分析同樣具價值。

- ✅ **底線（必達）**：MVP 可運作、端到端跑通、產出可重現。
- ✅ **核心成功**：預測分數與專家分數呈**統計顯著正相關**，且一致性指標（ICC / Bland–Altman）落在可討論範圍。
- ✅ **加分**：第二層關節定位 + 逐關節評分相較基線有可量測的提升；Grad-CAM 熱區量化落在臨床關節區域。
- ✅ **誠實價值**：即使結果有限，清楚的方法、消融分析與限制討論本身即為科展貢獻。

## 7. 創新點與貢獻

1. **可解釋性導向**：不只給分數，更用 Grad-CAM **量化證明**模型聚焦於臨床有意義的侵蝕/間隙區域。
2. **可重現的輕量流程**：整套在免費 Colab 上可重現，降低門檻。
3. **對小樣本與不平衡的誠實處理**：明確處理資料稀少與類別不平衡，如實報告限制——方法透明本身即為價值。
