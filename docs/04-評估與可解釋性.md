# 04・評估與可解釋性計畫

> 一句話定位：這份文件把「AI 自動 SvH 評分要怎麼算才算成功、怎麼證明模型看對地方」講清楚——用醫療界公認的一致性方法（ICC、Bland–Altman）取代「相關係數高就好」的陷阱，並把每個實驗的假設、變因、對照與預期產出列成可直接照做的清單。

適用對象：高中生作者 + 指導老師。閱讀順序建議：先讀「§0 三分鐘重點」與「§7 成功標準」，再回頭看細節。

---

## §0 三分鐘重點（先記這幾條）

- **相關係數高 ≠ 一致**。Pearson r 只看「一起上下」，模型把每張都低估 10 分，r 仍可能接近 1，但分數完全不可用。醫療評分要看**一致性**，主指標用 **ICC（組內相關係數）**，搭配 **Bland–Altman 圖**看系統性偏差與誤差範圍。
- **主指標一個就好，其餘是輔助**。回歸任務主指標建議 **ICC(2,1)**；次要：RMSE、MAE、Spearman、Bland–Altman 95% 一致性界限（LoA）。
- **小樣本一定要報信賴區間（CI）**。測試集若只有幾十到一兩百張，單一數字會騙人。用 **bootstrap** 算 95% CI，把不確定性誠實畫出來。
- **資料外洩會讓分數虛高**。同一病人的不同次/不同手 X 光不可橫跨 train/val/test，否則測試成績是假的。這是科展評審最常戳破的點。
- **Grad-CAM 要量化，不只貼圖**。用「熱區落在臨床關節區域的比例（命中率 / Pointing Game）」與「與關節標註框的重疊度（IoU）」給出數字。
- **負結果也有價值**。只要方法嚴謹、資料無洩漏、誠實報告不確定性與限制，「模型在小樣本上一致性有限」本身就是合格的科展結論。

## §1 查證重點：為何醫療評分一致性不能只看 Pearson

### 1.1 核心觀念

> 「高相關（high correlation）不等於高一致（high agreement）。只要其中一位評分者系統性地比另一位高（或低）一個近乎固定的量，就能得到近乎完美的線性相關，但兩者沒有任何一筆絕對一致。」——改寫自 Frontiers / PMC 評分者信度方法學文獻。

換句話說：

| 你想回答的問題 | 該用的工具 | 為什麼不能只用 Pearson |
|---|---|---|
| 模型分數和專家分數「會不會一起變動」 | Pearson r / Spearman ρ | 對「平移」與「縮放」誤差完全無感 |
| 模型分數和專家分數「數值上是否相同」 | **ICC（一致性/絕對一致）** | ICC 會懲罰系統性偏差，Pearson 不會 |
| 偏差有多大、會不會隨分數變大而變大 | **Bland–Altman 圖 + 95% LoA** | 一個 r 值看不出偏差方向與離散程度 |

### 1.2 醫療界對 SvH 分數一致性的標準做法（已查證）

- **ICC 是 SvH 評分信度的標準指標**：文獻報告 SvH 分數的**判讀者內 ICC 高達 0.99**，對「變化量」的敏感度 ICC 約 **0.84**（Oxford Rheumatology, 1999；PubMed 10534543）。這給我們一個對照基準：人類專家彼此/自己的一致性極高，AI 要被認可，ICC 至少要進入「good」以上區間。
- **最小可偵測變化量（SDC / SDD，Smallest Detectable Change）**：SvH 方法可定義 SDC，臨床試驗中曾以約 **2.2 分**作為「超過量測誤差、可視為真實進展」的門檻。SDC 是由 Bland–Altman 的一致性界限推導出來的——**這正是把 Bland–Altman 用在 SvH 上的直接前例**，我們可以引用此概念來解讀「模型誤差是否小於臨床可偵測變化」。
- **DREAM RA2 官方競賽用加權 RMSE**：RA2-DREAM Challenge（674 套，本計畫主資料集）官方排名用 **weighted RMSE**（關節層級狹窄/侵蝕）與 **weighted absolute error**（病人層級總損傷）。冠軍隊 weighted RMSE 約 0.38–0.44（Sun et al., 2022, *crowdsourcing* 論文）。**意義**：若使用此資料集，加總/逐關節 RMSE 應與官方度量對齊，方便和文獻比較；但 RMSE 是「次要指標」，一致性仍以 ICC + Bland–Altman 為主。

> 誠實標註：上述 ICC 0.99、敏感度 0.84、SDC≈2.2、DREAM 冠軍 RMSE 0.38–0.44 來自不同研究的不同資料集與不同評分版本（完整 SvH vs 簡化版），**僅供「量級參考」與設定期望，不可直接當成本研究的目標值或宣稱已達到**。本研究須用自己的資料重新計算，並報告自己的 CI。

### 1.3 ICC 怎麼選、怎麼判讀

- **選型**：模型 vs 單一專家共識分數的「絕對一致」→ 用 **ICC(2,1), two-way random, absolute agreement, single rater**（Shrout & Fleiss 慣例）。報告時務必寫清楚用哪一型，否則無法重現。
- **判讀（常用慣例，僅供溝通）**：<0.50 差、0.50–0.75 中等、0.75–0.90 良好、>0.90 優異。**一定要附 95% CI**，CI 很寬代表樣本太小、結論不穩。

## §2 完整指標清單（含意義、情境、判讀、主/次定位）

### 2.1 分數回歸（核心任務）

| 指標 | 意義 | 判讀方向 | 定位 |
|---|---|---|---|
| **ICC(2,1) 絕對一致** | 模型分數與專家分數的數值一致程度 | 越接近 1 越好；附 95% CI | **主指標** |
| **Bland–Altman**（偏差 bias + 95% LoA） | 平均系統偏差、誤差離散、是否隨分數放大 | bias 近 0、LoA 窄為佳；看有無漏斗狀趨勢 | **主圖（必畫）** |
| **RMSE** | 對大誤差敏感的平均誤差 | 越小越好；與 DREAM 加權 RMSE 對齊 | 次要 |
| **MAE** | 平均絕對誤差，單位=分，直覺 | 越小越好；可對照 SDC≈2.2 | 次要 |
| **Spearman ρ** | 排序一致性（病情輕重排序對不對） | 越接近 1 越好 | 次要 |
| **Pearson r** | 線性相關 | 僅輔助；**禁止單獨作為一致性結論** | 輔助 |
| **bias 的 95% CI / 各指標 bootstrap CI** | 不確定性 | CI 不跨 0 才談得上顯著偏差 | 必報 |

> 小技巧：SvH 總分常呈右偏（多數人分數低、少數高）。建議**同時報告**原始尺度與分層（輕/中/重）下的指標，避免被大量低分樣本「灌好看」。

### 2.2 嚴重度分級（MVP 可選的分類版本）

| 指標 | 意義 | 注意事項 | 定位 |
|---|---|---|---|
| **加權 F1 / macro-F1** | 各類別表現，抵消類別不平衡 | 不平衡時別只看 accuracy | **主指標** |
| **Quadratic Weighted Kappa (QWK)** | 有序分級的一致性，錯一級罰得比錯三級輕 | 比 accuracy 更適合「有序」損傷分級 | **強烈建議主指標之一** |
| 混淆矩陣 | 看錯在哪兩級之間 | 質性診斷用 | 次要 |
| Accuracy | 整體正確率 | 不平衡時會誤導，**不可單獨用** | 輔助 |
| Balanced Accuracy | 各類召回率平均 | 補 accuracy 的不平衡盲點 | 次要 |

### 2.3 關節定位（進階任務）

| 指標 | 意義 | 定位 |
|---|---|---|
| **mAP@0.5 / mAP@[.5:.95]** | 偵測框與真值框的整體偵測品質 | 主指標 |
| 每關節定位命中率 | 正確框到目標關節的比例 | 次要 |
| 漏檢 / 誤檢數 | 臨床上漏掉關節的代價 | 次要（誠實報告） |

### 2.4 可解釋性（Grad-CAM，量化版）

| 指標 | 意義 | 怎麼算 | 定位 |
|---|---|---|---|
| **熱區命中率（Pointing Game）** | 熱區最高點是否落在臨床關節區域內 | 取 Grad-CAM 最大值點，檢查是否落在標註的關節框/侵蝕區內，算整體命中率 | **主指標** |
| **熱區–標註重疊度（IoU）** | 熱區（門檻二值化後）與關節/侵蝕標註的重疊比例 | 熱區用固定門檻（如前 20% 強度）二值化，與標註框算 IoU | **主指標** |
| 熱能集中比例（energy ratio） | 落在臨床關節區內的 Grad-CAM 總能量佔比 | Σ(關節區內熱值)/Σ(全圖熱值) | 次要 |
| 質性檢視 | 隨機抽樣由「醫學把關者」目視合理性 | 抽 N 張盲評打分 | 輔助（必做但不可當唯一證據） |

> 參考量級（他人研究、非目標）：胸腔 X 光基準研究中 Grad-CAM 對標註區的 IoU 約 0.57，較進階方法約 0.74（Nature Machine Intelligence, 2022）。可用來說明「為何單純 Grad-CAM 的 IoU 通常偏低、需要謹慎解讀」。

## §3 統計與不確定性（科展加分關鍵）

- **一律附 95% CI**：ICC、RMSE、MAE、F1、IoU、命中率全部都要 CI。
- **小樣本用 bootstrap**：對測試集重抽樣（建議 1,000–2,000 次），取指標分布的 2.5/97.5 百分位當 95% CI。這是測試集只有數十到一兩百張時最誠實的做法。
- **顯著性檢定（謹慎使用）**：
  - 模型 vs 專家是否有系統偏差：對配對差值做 **配對 t 檢定或 Wilcoxon 符號秩**（非常態用後者）。
  - 兩模型誰較好：對「每張影像的誤差」做配對檢定（如 Wilcoxon），或直接比較 bootstrap CI 是否重疊。
- **多重比較**：消融做很多組比較時，提醒可能要校正（如 Holm/Bonferroni），至少要在文中聲明「未校正、屬探索性」，避免過度宣稱。
- **報告模板（每個結果都照這格式）**：`指標 = 值 [95% CI 下界, 上界]，n = 樣本數`。

## §4 實驗矩陣（假設 / 變因 / 對照 / 預期產出）

> 共同原則：**固定隨機種子、固定 train/val/test 切分（病人層級不外洩）、固定測試集**。所有實驗在「同一個鎖定的測試集」上比較，且測試集只在最後評估時動用一次。

| # | 實驗 | 假設(H) | 自變因 | 控制/對照 | 主要產出 |
|---|---|---|---|---|---|
| E1 | **MVP 基線**（整圖→總分回歸） | CNN 遷移學習能與專家分數產生正向、可量測的一致性 | 模型存在 vs 不存在 | 與「平均分基準(predict mean)」「隨機」基準比較 | ICC + Bland–Altman + RMSE/MAE（皆含 CI），建立可比較起點 |
| E2 | **進階：關節定位 + 逐關節評分** | 先定位關節再逐關節評分，一致性優於整圖基線 | 管線（整圖 vs 定位後逐關節） | E1 為對照，測試集相同 | 兩者 ICC/RMSE 的差值 + 配對檢定 + CI 是否重疊 |
| E3a | **消融：資料增強** | 增強提升泛化、降低過擬合 | 有/無增強（其餘固定） | 同骨幹、同切分 | ΔICC、Δval-test 落差（看過擬合改善） |
| E3b | **消融：骨幹** | 不同骨幹影響有限或有最佳選擇 | ResNet vs EfficientNet vs MobileNet | 同訓練設定 | 各骨幹指標表 + 參數量/速度對照 |
| E3c | **消融：類別不平衡處理** | 加權損失/重採樣改善少數(重症)類 | 有/無不平衡處理 | 同模型 | 分層(輕/中/重)指標、重症類召回率、QWK |
| E4 | **可解釋性（Grad-CAM 量化）** | 模型主要依據臨床關節（侵蝕/間隙）區域 | — | 與「隨機熱區」「邊框熱區」基準比命中率 | 命中率、IoU、energy ratio（含 CI）+ 抽樣盲評 |
| E5 | **外部驗證（若資料可得）** | 模型可泛化到另一來源資料 | 資料來源（內部 vs 外部） | 同一鎖定模型，不再調參 | 外部 ICC/RMSE 與內部落差，誠實討論泛化 |

> E5 若拿不到第二份資料：改用 **病人層級交叉驗證 / 重複切分** 來估計穩定度，並明說這是泛化的「弱證據」而非外部驗證。

## §5 Grad-CAM 量化評估操作步驟（可照做）

1. **準備臨床參考區**：對測試集（或其子集）標出每個目標關節的框（MCP/PIP 等）；若有侵蝕/狹窄位置更佳。可請醫學把關者協助或用 E2 的偵測框。
2. **產生熱圖**：對每張影像、對「預測分數」這個輸出做 Grad-CAM，得到 0–1 正規化熱圖。
3. **命中率（Pointing Game）**：取熱圖最大值點，若落在任一目標關節框內記為命中；命中率 = 命中張數 / 總張數。
4. **IoU**：將熱圖以固定門檻（例：保留前 20% 強度）二值化，與關節框聯集算 IoU，報平均與 CI。
5. **能量比**：落在關節區內的熱值總和 / 全圖熱值總和。
6. **對照基準**：和「隨機熱區」「只看影像邊緣」比較，證明命中率顯著高於亂猜（用 bootstrap CI / 檢定）。
7. **盲評**：抽 20–30 張，讓醫學把關者在不知預測對錯下，判斷熱區是否落在臨床合理位置（合理/部分/不合理），報比例。

> 誠實準則：Grad-CAM 是「事後解釋」，不等於模型真正的因果依據。結論措辭用「熱區與臨床區域**重疊度為 X**」，**不要**寫成「模型已學會臨床特徵」。

## §6 原始評估規劃的盲點與改善

| # | 原計畫盲點 | 風險 | 本文改善 |
|---|---|---|---|
| B1 | 一致性只列 Pearson/Spearman | 相關高但偏差大時，做出「一致」的錯誤結論 | 改以 **ICC(2,1) 為主**，**Bland–Altman 必畫**，Pearson 降為輔助且禁止單獨下結論 |
| B2 | 無信賴區間 / 無 bootstrap | 小測試集單一數字過度自信 | 所有指標**強制報 95% CI**，小樣本用 **bootstrap** |
| B3 | 切分只說「同病人不跨集」但未檢核 | 同病人多手/多時點外洩→成績虛高 | 明列**病人層級切分檢核清單**（見 §8），並報告切分後各集分布 |
| B4 | 分級只用 Accuracy/F1 | 有序+不平衡時 accuracy 誤導 | 加 **QWK**、balanced accuracy、分層指標 |
| B5 | Grad-CAM 只「質性 + 比例」 | 缺可量化、可重現證據 | 加 **命中率 / IoU / energy ratio + 對照基準 + CI** |
| B6 | 未對齊資料集官方度量 | 無法與文獻公平比較 | 對齊 DREAM **加權 RMSE** 作次要指標 |
| B7 | 未設「測試集只用一次」紀律 | 反覆看測試集→變相調參、樂觀偏差 | 鎖定測試集，**最後一次性評估**；調參只用 val |
| B8 | 成功標準偏模糊（「顯著正相關」） | 易被評審追問「一致還是相關」 | 改為**以 ICC/CI 為門檻的分層成功標準**（§7） |
| B9 | 未量化測試集太小的後果 | 結論不穩 | 用 CI 寬度與 bootstrap 分布**主動呈現不確定性** |

## §7 務實且誠實的成功標準

> 原則：**標準寫在做實驗之前**，避免「事後挑好看的指標」。用「分層」設定，保住 MVP 底線，也給進階留空間。

| 層級 | 標準（皆需在鎖定測試集上、附 95% CI） |
|---|---|
| **必達（MVP 合格）** | (1) 端到端可運作、可重現；(2) 模型顯著優於「預測平均分」基準（誤差更低且 CI 不重疊）；(3) ICC 點估計達「中等」(≥0.50) 區間、**並如實報告 CI**；(4) Bland–Altman 已畫、偏差方向已討論；(5) 切分無病人外洩（附檢核） |
| **理想（表現良好）** | ICC ≥ 0.75（良好）且 CI 下界仍 > 0.5；MAE 接近或低於 SvH 之 SDC 量級（約數分內）；Grad-CAM 命中率顯著高於隨機基準 |
| **進階（強成果）** | E2 逐關節管線在相同測試集上 ICC/RMSE 顯著優於 E1；外部驗證(E5)仍維持中等以上一致性 |

### 「負結果也具科展價值」的論述

科展評審看重**方法嚴謹與誠實**，不是漂亮數字。若最終 ICC 只達中等、或外部驗證掉很多，仍可寫成有價值的結論，只要：

1. 資料切分無洩漏、流程可重現、種子固定；
2. 所有指標附 CI，明確指出「小樣本導致的高不確定性」就是發現之一；
3. 用 Bland–Altman 指出**系統性偏差的方向與大小**（例：模型對重症普遍低估），這對未來改進是真知識；
4. 明確區分「相關 vs 一致」，示範為何看似不錯的相關其實一致性有限——**這本身就是一個有教育意義的科學結論**。

### 避免過度宣稱準則（自我檢查）

- 不寫「可取代醫師 / 可用於診斷」→ 寫「**輔助評分**，需專業與臨床驗證」。
- 不寫「模型學會了侵蝕特徵」→ 寫「熱區與臨床區域**重疊度為 X[CI]**」。
- 不把驗證集調出的最佳值當成測試結論；測試集結果才是對外數字。
- 不引用他人研究的指標當成自己達標；他人數字只作「量級對照」。
- 任何「最佳/顯著/優於」都要附 CI 或檢定，否則不下結論。

## §8 落地檢核清單（做實驗時逐項打勾）

**資料與切分**
- [ ] 切分以**病人(patient ID)為單位**，同病人所有影像只進同一集
- [ ] 列出 train/val/test 的張數、病人數、分數分布（總分與輕/中/重比例）
- [ ] 確認**測試集在調參期間完全未被看過**
- [ ] 影像前處理（尺寸/對比/增強）參數記錄於研究日誌，可重現

**指標與統計**
- [ ] 主指標：回歸 ICC(2,1)、分級 QWK/加權F1，已寫明
- [ ] Bland–Altman 圖已畫（bias + 95% LoA + 是否漏斗狀）
- [ ] 每個指標都附 95% CI；小樣本用 bootstrap（記錄重抽次數與種子）
- [ ] 與基準（平均分/隨機）比較且做配對檢定或比 CI 重疊
- [ ] 報告格式統一：`值 [CI下,CI上], n=…`

**可解釋性**
- [ ] Grad-CAM 命中率 + IoU + energy ratio 已算（含 CI）
- [ ] 有對照基準（隨機/邊緣熱區）
- [ ] 醫學把關者盲評 20–30 張，記錄比例
- [ ] 結論措辭未過度宣稱（重疊度 ≠ 因果）

**再現性與倫理**
- [ ] 隨機種子、套件版本、超參數、checkpoint 全部記錄
- [ ] 研究日誌持續更新（評審當天需攜帶）
- [ ] 免責聲明：輔助評分、非診斷、需臨床驗證
- [ ] 僅用去識別化、授權清楚之資料
