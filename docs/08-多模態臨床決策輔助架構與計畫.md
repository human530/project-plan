# 多模態臨床決策輔助：架構、範圍與計畫

> 一句話定位：把目前「單張手部 X 光 → SvH 損傷分數」的影像模型，**有節制地**擴展成一個結合影像、臨床與實驗室資料的多模態臨床決策輔助（multimodal clinical decision support, mCDS）藍圖——但嚴守科展範圍，先把影像核心做扎實，多模態以「最小可行加法」呈現，其餘列未來展望。

> 本文件的文獻依據見 `docs/07-文獻回顧總覽與最權威分析.md` 與 `docs/lit/` 三份逐篇分析。所有外部數據均依 PubMed 規範附 DOI。

---

## 0. 為什麼要談「多模態」——以及為什麼要克制

臨床上醫師不會只看一張 X 光就決策；他們同時看 **影像 + 發炎指標（CRP/ESR）+ 抗體（anti-CCP/RF）+ 疾病活動度（DAS28）+ 病史**。文獻趨勢也顯示，把這些模態融合，對「疾病活動度、放射學進展、治療反應」的預測力高於單一模態。

但本專案是**高中個人、免費 Colab、單一公開影像資料集**為主的科展。多模態若做過頭會：資料拿不到、樣本太小過擬合、範圍蔓延做不完。因此本文件的核心主張是：

> **影像核心（SvH 評分）= 必達；多模態 = 受控的「加一層」示範；完整 mCDS 系統 = 未來展望。**

---

## 1. 範圍分層（多模態維度）

| 層級 | 模態 | 做什麼 | 本屆定位 |
|------|------|--------|----------|
| **M0 影像核心** | 單模態（X 光） | SvH 損傷分數（已完成 MVP 程式骨架） | ✅ 必達 |
| **M1 影像 + 表格** | X 光 + 結構化臨床/實驗室特徵 | 把影像特徵（或預測分數）與 CRP、anti-CCP、年齡等表格特徵串接，預測「嚴重度/是否快速進展」，並用 SHAP 顯示各特徵貢獻 | 🎯 進階加分（若有對應資料） |
| **M2 多影像模態** | X 光 + MRI/US | 比較或融合不同影像模態的損傷評估 | 🔭 未來展望（資料極難取得） |
| **M3 完整 mCDS** | 影像 + 臨床 + 組學 + 縱貫追蹤 | 治療反應 / 反事實 / 惡化軌跡預測 | 🔭 未來展望 |

> 關鍵現實：M1 需要「同一批病人同時有影像與臨床/實驗室欄位」的資料。多數公開影像資料集**沒有**完整臨床欄位。因此 M1 是否可行，取決於資料（見 docs/02）；若不可行，可用**模擬/文獻參數的合成表格特徵**做「方法示範」，並誠實標註為示範而非臨床結論。

## 2. 多模態系統架構（M1 為主）

```
   ┌──────────────────────────────────────────────────────────────┐
   │              多模態臨床決策輔助（mCDS）— M1 架構                 │
   └──────────────────────────────────────────────────────────────┘

   [手部 X 光]                         [結構化表格特徵]
        │                          CRP/ESR、anti-CCP、RF、
        ▼                          年齡、病程、DAS28 …
   ┌─────────────┐                        │
   │ 影像分支     │                        ▼
   │ CNN 骨幹     │                 ┌─────────────┐
   │ (已建置)     │                 │ 表格分支     │
   └─────────────┘                 │ MLP / GBDT   │
        │ 影像特徵向量 / 預測分數     └─────────────┘
        │                                 │ 表格特徵向量
        └──────────────┬──────────────────┘
                       ▼
              ┌──────────────────┐
              │  融合層 (fusion)  │  late fusion（建議，穩健）
              │  concat → MLP    │  或 early/intermediate fusion
              └──────────────────┘
                       │
                       ▼
        ┌──────────────────────────────┐
        │ 輸出：嚴重度 / 快速進展風險     │
        │ + SHAP 各模態/特徵貢獻解釋      │
        │ + 影像端 Grad-CAM 區域解釋      │
        └──────────────────────────────┘
```

**融合策略建議（小樣本優先）**：
- **Late fusion（後期融合，建議起點）**：影像分支與表格分支各自訓練到可用，再把兩者的輸出/特徵串接給一個小融合頭。最穩健、最易除錯、最不易過擬合。
- Intermediate fusion（中期融合）：把影像特徵向量與表格特徵向量串接後共同訓練，表達力較強但較易過擬合，列為進階比較。
- 避免一開始就做複雜的 cross-attention 融合（樣本太少撐不起）。

## 3. 與現有程式骨架的銜接

目前 `src/raxray` 已具備影像分支（backbone + 頭）、評估（含 ICC/SHAP 之外的指標）、Grad-CAM。擴到 M1 只需新增：

| 新增模組 | 內容 | 對應現有 |
|----------|------|----------|
| `data/tabular.py` | 載入/標準化表格特徵、缺值處理 | 對齊 `data/dataset.py` 的 patient_id |
| `models/fusion.py` | 表格分支（MLP）+ late-fusion 頭 | 接 `models/backbone.py` 的特徵 |
| `explain/shap_report.py` | 對表格/融合輸出做 SHAP 貢獻分析 | 對齊 `gradcam.py` 的解釋理念 |
| 評估擴充 | 加 AUROC、AUPRC、calibration、決策曲線 | 擴 `evaluate.py` |

> 重要：表格分支與融合一律沿用 **病人層級切分**（docs/02），SHAP 與 Grad-CAM 並列為「雙模態可解釋性」。

---

## 4. 多模態的評估增補（接 docs/04）

多模態 / 決策任務除了既有的 ICC/Bland–Altman/QWK，還應加上：

| 任務 | 指標 | 注意 |
|------|------|------|
| 二元風險（如「是否快速進展」） | AUROC + AUPRC（不平衡時看 AUPRC）、校準曲線、Brier score | 小樣本一律附 bootstrap 95% CI |
| 單模態 vs 多模態增益 | ΔAUROC + DeLong 檢定、淨重分類改善 | 證明「多模態真的有加值」而非更複雜而已 |
| 可解釋性 | SHAP（表格）+ Grad-CAM（影像）一致性 | 解釋是否落在臨床上合理的特徵 |
| 決策效用 | 決策曲線分析（DCA） | 展現臨床可用性，加分 |

## 5. 風險與克制原則（多模態特有）

| 風險 | 因應 |
|------|------|
| 找不到「影像 + 臨床」配對資料 | M1 退為「合成/文獻參數表格特徵」的方法示範，明確標註非臨床結論；或直接把 M1 列未來展望，全力做好 M0 |
| 樣本太小、特徵太多 → 過擬合 | 嚴格特徵選擇（LASSO）、late fusion、強正則化、巢狀交叉驗證 |
| 多模態「看起來厲害」但無增益 | 一律做單模態 baseline 對照 + ΔAUROC 顯著性檢定，誠實報告 |
| 過度宣稱為臨床決策工具 | 定位「輔助、研究示範」，附免責；遵守報告規範（見 docs/07 對 CLAIM/TRIPOD-AI 的整理） |

## 6. 落地計畫（接 docs/05 時程）

- **2026 暑–秋**：先完成 M0 影像核心（已具骨架）。同時調查是否存在「影像 + 臨床欄位」配對資料（決定 M1 可行性）。
- **2026 冬–2027 春**：若 M1 可行 → 實作表格分支 + late fusion + SHAP，做單模態 vs 多模態對照消融；若不可行 → 以合成表格特徵做方法示範，並把重心放回影像進階（逐關節）。
- **2027 春–夏**：完成多模態可解釋性（SHAP + Grad-CAM）與決策曲線分析，整合進報告。
- **全程**：嚴守「先單模態 baseline，再加多模態並證明增益」的科學紀律。

## 7. 文獻依據（已完成，According to PubMed）

本架構的關鍵主張均有 PubMed 文獻支持（完整對比見 docs/07 與 docs/lit/B）：

- **late fusion + 樹模型 + SHAP 預測快速放射學進展**：可行且可解釋——血漿代謝體 + 臨床 CjBM AUC 0.800 [DOI](https://doi.org/10.1186/s13075-025-03576-x)；LASSO + 多源特徵鑑別診斷 AUC 0.854（SHAP）[DOI](https://doi.org/10.3389/fimmu.2025.1614631)。
- **單模態 vs 多模態須驗證增益**：加入代謝體可顯著改善既有模型（P=0.035）[DOI](https://doi.org/10.1186/s13075-025-03576-x)；但全基因型對 MTX 反應增益可忽略（2432 人反面證據）[DOI](https://doi.org/10.1111/joim.20087)。
- **小樣本防過擬合**：巢式交叉驗證 [DOI](https://doi.org/10.3390/jcm13133890)、自監督預訓練與外部/前瞻驗證 [DOI](https://doi.org/10.1016/j.patter.2022.100592)。
- **人機協作真實增益**：RATING 使放射醫師準確率 41.4%→64.0% [DOI](https://doi.org/10.1016/j.patter.2022.100592)。
- **報告規範**：對齊 TRIPOD+AI [DOI](https://doi.org/10.1136/bmj.q824) 與 DECIDE-AI「準確 ≠ 臨床有用」[DOI](https://doi.org/10.1038/s41591-022-01772-9)。

> 研究缺口：目前**尚無研究同時融合影像 + 臨床 + 實驗室 + 組學四域並完成外部驗證**——本專題以「最小可行多模態示範」切入，完整融合列為長期方向。
