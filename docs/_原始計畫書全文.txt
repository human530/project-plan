研究計畫書
類風濕性關節炎手部 X 光之 AI 自動損傷評分
目標賽事:臺灣國際科學展覽會(TISF)・高中・個人　|　目標送件:2027 年 10–11 月　|　製表:2026 年 6 月
一、計畫總覽
一句話: 開發一套能從手部 X 光自動產生類風濕性關節炎(RA)損傷分數(以 Sharp–van der Heijde 分數為基礎)的 AI 模型,並驗證其與專家評分的一致性。
做什麼: 輸入一張手部 X 光,輸出量化的關節損傷分數(骨侵蝕 + 關節間隙)。
怎麼做: 以遷移學習的卷積神經網路(CNN)為核心,分層推進:先做整圖評分基線,再做關節定位後逐關節評分;全程與專家分數量化比對,並用 Grad-CAM 檢驗模型依據。
為什麼: 臨床上 Sharp 評分準確但費時、需專業、且有判讀者間差異;自動化能加速、標準化並輔助醫師,具實際價值。
二、研究背景與動機(Why)
類風濕性關節炎是慢性自體免疫發炎性關節炎,常侵犯手部關節,造成骨侵蝕與關節間隙變窄,需長期影像追蹤以評估病程與治療反應。
臨床以 Sharp–van der Heijde(SvH)分數逐關節量化損傷(分別評「骨侵蝕」與「關節間隙狹窄」再加總)。此評分準確,但人工逐關節判讀非常耗時、需要專業訓練,且不同判讀者之間存在差異。
若能用 AI 自動、快速、且一致地估計損傷分數,可減輕醫師負擔、提升標準化、並作為追蹤與研究的輔助工具——這就是本研究的價值所在。
三、研究問題與假設
主要問題:深度學習模型能否從手部 X 光自動估計 SvH 損傷分數,並與專家評分達到高度一致?
研究假設:經遷移學習的 CNN 可使預測分數與專家分數呈顯著正相關、誤差可接受;加入關節定位可進一步提升準確度。
次要問題:模型主要依據哪些影像區域做判斷?(以 Grad-CAM 檢驗是否對應骨侵蝕與關節間隙等臨床特徵)
四、方法框架(How)
整體流程:影像輸入 → 前處理 →(進階:關節定位 / 切割)→ 模型評分 → 與專家分數比對 → Grad-CAM 可解釋性分析。
採「分層推進」策略,確保每一層都有可交付成果,避免一次做到底而做不完:

五、資料規劃
主要資料集:RA2 DREAM Challenge(674 套手 / 腕 / 足 X 光,附專家 SvH 分數;Synapse ID:syn20545111)。
取得方式(最大關卡):該資料集影像需「向作者提出合理申請」才能取得,並非直接下載;建議及早啟動,並請指導老師 / 家長或學校協助申請。
後援資料:其他公開 RA 手部 X 光資料(如 Kaggle、Mendeley)與公開正常手部 X 光作對照,降低單一資料來源風險。
前處理:影像尺寸標準化、對比 / window-level 調整、資料增強(旋轉、翻轉、亮度);以加權或重採樣處理類別不平衡。
資料切分:切成訓練 / 驗證 / 測試,並確保同一病人不跨集,避免資料外洩高估準確度。
資料倫理:僅使用去識別化、授權清楚的公開資料,遵守資料使用同意與研究倫理。
六、模型與訓練
骨幹模型:預訓練 CNN(ResNet / EfficientNet / MobileNet)接回歸或分類頭,以遷移學習微調。
關節定位(進階):以物件偵測 / 分割模型框出關節後裁切,再逐關節評分。
訓練設定:Colab GPU 訓練;回歸用 MSE / MAE、分級用加權交叉熵;採 early stopping,模型與資料定期 checkpoint 至 Google Drive。
工具:Python、PyTorch 或 Keras、OpenCV、Grad-CAM 套件、scikit-learn、Git 版本控制。
七、實驗設計與評估指標
評估以「與專家分數的一致性」為核心:

規劃實驗:
基線:MVP 整圖評分,建立可比較的起點。
進階比較:關節定位 + 逐關節評分 對比 基線,看是否提升。
消融實驗:資料增強、骨幹選擇、不平衡處理各自的影響。
可解釋性:Grad-CAM 驗證模型是否看對臨床特徵。
(若可行)外部驗證:在另一資料集上測試,討論泛化能力。
成功標準(保守): MVP 可運作、預測與專家分數顯著正相關、可解釋性合理。即使是誠實的負結果加上分析,也具科展價值。
八、創新點與貢獻
可解釋性導向:不只給分數,還用 Grad-CAM 證明模型聚焦於臨床上有意義的侵蝕 / 間隙區域。
可重現的輕量流程:整套在免費 Colab 上可重現,降低門檻。
對小樣本與不平衡的誠實處理:明確處理資料稀少與類別不平衡,並如實報告限制——方法透明本身即為價值。

十一、資源與協助
工具 / 算力:Colab(免費 GPU)+ Google Drive + 開源函式庫,幾乎零成本。
技術協助:卡關時可請教的老師 / 學長 / 家人。
醫學 / 領域把關:請一位懂醫學或放射的人確認臨床敘述與標註合理、避免錯誤與過度宣稱。
資料申請協助:受限資料集可能需成人或學校單位出面申請。
指導老師:TISF 需學校推薦,指導老師也利於借設備與審稿。
十二、限制與研究倫理
本作品為研究與輔助評分用途,非臨床診斷;任何真實應用需專業把關與臨床驗證。
小樣本與單一資料來源會限制泛化能力,須誠實討論。
僅使用去識別化、授權清楚的資料;遵守研究倫理,並配合 TISF 抄襲比對系統。
十三、未來展望
在本題穩固後,可延伸為更大的系統:擴充到多病種分類(RA / PsA / OA / 痛風)、由現在影像預測未來惡化軌跡、以及「有藥 vs 無藥」的治療效果 / 反事實示意。這些列為未來方向,不在本屆強求。
